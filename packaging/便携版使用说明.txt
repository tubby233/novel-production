【小说生成器 · 便携版使用说明】

一、这是什么
    这是一个 Windows 桌面小说生成应用（PySide6 + DeepSeek API）。
    本文件夹里已经打包好 Python 解释器、Qt 界面库与全部第三方依赖，
    **目标电脑不需要安装 Python，也不需要联网安装任何东西**。

二、系统要求
    · Windows 10 或 Windows 11（64 位）
    · 需要能访问 DeepSeek API（或你自己的 OpenAI 兼容中转服务）
    · 不需要管理员权限（放在 U 盘、桌面、任意文件夹都可以）

三、怎么运行
    1. 双击本文件夹里的  NovelGen.exe
    2. 首次运行会自动在本文件夹生成 config.json 与 chapters.json
    3. 打开菜单  设置 → API 与模型，填入你的 api_key，点「测试连接」确认可用
    4. 在左侧粘贴或导入大纲 → 点「切分章节」（此时会让你输入小说名完成"立项"）
       → 工具栏「全量生成」
    5. 运行日志默认不显示；需要时点菜单  帮助 → 运行日志，会在新窗口里打开

四、小说以"项目"组织（一部小说一个文件夹）
    · 每次「切分章节」都会触发立项：程序请你输入小说名，并在"项目根目录"
      （默认 我的文档\NovelGenProjects，可在 设置 → 界面与流程 里修改）
      下新建一个以小说名命名的文件夹，存放这部小说的全部数据：
          小说名\chapters.json       章节、正文、检查结果、状态、大纲快照
          小说名\conversations.json  全部生成/检查对话（含思维链）
          小说名\outline.txt         大纲原文
          小说名\project.json        项目信息
    · 对话会在 **AI 每次回复完成后**、以及关闭项目/切换项目/关闭软件时自动存档，
      所以重新打开项目可以接着之前的对话继续，正文也不会被清空。
    · 读取已有小说：菜单  项目 → 打开项目（也可"从文件夹打开…"直接选目录）。
      下次启动会自动打开上次使用的那部小说。
    · 重新切分时，如果这部小说已经立项，提示会说明"旧内容已存档、不会丢失"。
    · 备份一部小说 = 拷贝它的项目文件夹。

五、整个文件夹可以直接搬走
    · 把 NovelGen 文件夹整体拷贝/移动到任何 Win10/Win11 电脑，双击即可运行。
    · 请保持文件夹内部结构不变（NovelGen.exe 与 _internal 必须在一起）。
    · config.json 就在 exe 旁边，跟着文件夹一起走；小说数据在项目文件夹里
      （默认在"我的文档"，如需随身携带，可在设置里把项目根目录改到本文件夹下）。
    · 如果放进 C:\Program Files 这类不允许写入的目录，程序会自动把配置
      改存到 %APPDATA%\NovelGen（不会报错）。
    · 也可以显式指定数据目录（例如想让配置放在 U 盘某个位置）：
        命令行执行
        set NOVELGEN_DATA_DIR=D:\NovelGenData
        NovelGen.exe

六、常见问题
    1. 双击没反应 / 闪一下就没了
       本文件夹里会生成 crash.log，把它的内容发给开发者即可定位。
       常见原因：杀毒软件拦截、解压不完整。请先确认 _internal 文件夹完整，
       并把整个文件夹加入杀毒软件白名单。
    2. 提示"API 密钥无效"
       检查 api_key 是否填对、是否过期；中转服务要确认 key 与 base_url 配套。
    3. 提示 429
       账号并发超限，在工具栏或设置里把「并发数」调小（默认 8）。
    4. 想换电脑后继续同一部小说
       把该小说的项目文件夹（或整个 NovelGen 文件夹）拷过去，
       再用 项目 → 打开项目 打开即可。
    5. 点了"重新生成"好像没反应
       章节会立刻显示为"排队中"，界面上方也会出现蓝色提示条：
       任务已排在队列末尾，等并发配额空出就自动开始。
    6. 停止任务是不是出错了
       不是。"停止本章 / 停止全部"、清空对话这类手动操作触发的中断只记一条 info
       日志（"已按你的要求停止…"），保留已收到的内容，不会当作报错、也不会自动弹日志窗口。
    7. 清空生成对话之后怎么按大纲重来
       清空后本章状态会回到"待生成"，顶部按钮变成「重新生成（按大纲）」，
       点它就是重新把本章大纲发给 AI，而不是按修改建议重写。
    8. 某一章一直显示"排队中"
       点工具栏「任务队列」打开右侧面板看一眼：
       在队列里就说明还没轮到，可以把它拖到队首、或调大并发数、或点「移出队列」取消；
       不在队列里则是异常遗留状态，程序会自动把它恢复成"待生成/待检查"。
    9. 想彻底重置
       删除 config.json（重置设置）——下次启动会自动重新生成一份默认配置；
       再删除不需要的项目文件夹即可。
   10. 切分了新大纲，原来的小说会不会被覆盖
       不会。从点「切分章节」到新项目建立为止，程序**不会写任何数据**，
       原项目的文件夹保持原样；用 项目 → 打开项目 随时能读回原来的进度。

七、卸载
    直接删除整个 NovelGen 文件夹即可，不会往系统里写其他东西
   （除非它回退使用过 %APPDATA%\NovelGen，可一并删除）。
    注意：小说项目默认存放在"我的文档\NovelGenProjects"，删除程序不会删掉它们。

八、技术信息
    打包方式：PyInstaller onedir（绿色文件夹）
       NovelGen.exe      程序主体
       _internal\        运行库（Python 解释器、Qt、openai、httpx、CA 证书、资源）
    自检（不需要 Python 环境即可验证本文件夹是否完整）：
       命令行执行
        set NOVELGEN_SELFCHECK=1
        NovelGen.exe
      随后查看本文件夹里的 selfcheck.txt，末尾出现"全部通过"即表示可用。
